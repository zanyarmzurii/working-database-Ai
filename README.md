# WhatsApp Bot with AI Integration

A Node.js WhatsApp automation bot powered by `whatsapp-web.js` and Google Generative AI (Gemini). Built to deploy seamlessly on platform like Railway.

---

## 🚀 Features

* **Automated WhatsApp Responses**: Built using `whatsapp-web.js`.
* **AI Integration**: Powered by Google's Generative AI.
* **Railway Ready**: Optimized configuration for cloud execution and deployment.
